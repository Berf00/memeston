# Memestone

Un gioco di carte in stile Hearthstone con carte meme tra amici. Si gioca contro il computer, direttamente dal browser.

## Aggiungere una carta
Apri `carte.js`: in cima trovi le istruzioni. Copia un blocco `{ ... }`, cambia i valori e salva.
Per usare una foto invece dell'emoji, mettila nella cartella `img` e scrivi `immagine: "img/nomefoto.jpg"`.
